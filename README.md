## 📋 Executive Summary
This project addresses regional self-service banking operations and hardware infrastructure risk across Indonesian metropolitan branches (*Jakarta, Surabaya, Medan, Bandung, Makassar*). The solution bridges geospatial performance tracking with granular vendor warranty compliance audits.
